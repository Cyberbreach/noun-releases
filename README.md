# NouN IPTV — Releases

App Android TV pour Algérie francophone + plugin IPS4 ddlstreamitaly.cc.

## Téléchargements

### App Android TV (NouN IPTV)
- [NounStream-IPTV-latest.apk](./NounStream-IPTV-latest.apk) — dernière build
- Compatible : Android TV 6+ (Skyworth, MiBox, Fire TV, ...)
- Installation : ADB `adb install -r` ou side-load via clé USB

### Plugin IPS4 ddlstreamitaly.cc (NouN IPTV Keys)
- [noun-iptv-keys-2.1.6.xml](./noun-iptv-keys-2.1.6.xml) — plugin pour générer les codes 16 chiffres
- Installation : AdminCP → Plugins → Upload Plugin → choisir le XML
- Workflow : Servers → Lines → "+ Key" → code 16 chiffres → client le saisit sur l'app
